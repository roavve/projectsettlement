# clarificationDate (გარკვევის თარიღი) — როდის იცვლება

## მთავარი წესი

⭐ **როგორც კი გარკვევის თარიღი ერთხელ დაყენდება, ის აღარასოდეს იცვლება.**
(თუ `clarificationDate` უკვე შევსებულია — რაც არ უნდა შეიცვალოს, თარიღი იგივე რჩება.)

## სტატუსების ქართული შესაბამისობა

| სტატუსი | ქართულად |
|---|---|
| ORDER_INCOMPLETE | გამოუყენებელი |
| ORDER_COMPLETE | შევსებული |
| YELLOW_AMOUNT | დასასრულებელი |
| CANCELED | გაუქმებული |
| IN_PROGRESS | პროცესში |
| RETURNED | დაბრუნებული |

## გარკვევის თარიღი იცვლება

თარიღი ყენდება მხოლოდ მაშინ, როცა **თარიღი ჯერ არ არის დაყენებული** და დამატებით სრულდება ქვემოთ ჩამოთვლილიდან თუნდაც ერთი:

1. **ახალი სტატუსი არის „პროცესში" და ვწერთ ახალ პროექტის ნომერს, ან იცვლება პროექტის ნომერი.**
2. **MTB ორდერის სტატუსი იცვლება „პროცესში"-დან „დაბრუნებულზე"** (გადარიცხვის ტიპი 6).
   - „MTB"-ად ითვლება, თუ ან ახალი, ან არსებული ორდერის ნომერი არის „MTB".

## გარკვევის თარიღი არ იცვლება

- როცა გარკვევის თარიღი **უკვე დაყენებულია** (მთავარი წესი).
- როცა პროექტის ნომერს ვწერთ, მაგრამ ახალი სტატუსი **არ არის „პროცესში"** (და არც MTB ტიპი 6-ის „პროცესში" → „დაბრუნებული" გადასვლაა).
- როცა **მხოლოდ ორდერის ნომერს** ვამატებთ.
- როცა **შენიშვნაში** რაიმე ტექსტს ვწერთ.

## ცხრილი (ხშირი შემთხვევები)

| # | უკვე დაყენებული? | ახალი სტატუსი | რა შეიცვალა | შედეგი |
|---|:----------------:|---|---|:---:|
| 1 |       არა        | არა „პროცესში" | პროექტის ნომერი დაიწერა/შეიცვალა | ❌ არ იცვლება |
| 2 |    არა && კი     | არა „პროცესში" | MTB, ტიპი 6, „პროცესში" → „დაბრუნებული" | ✅ ყენდება |
| 3 |    არა && კი     | **„პროცესში"** | პროექტის ნომერი დაიწერა/შეიცვალა | ✅ ყენდება |
| 4 |       არა        | ნებისმიერი | მხოლოდ ორდერის ნომერი დაემატა | ❌ არ იცვლება |
| 5 |       არა        | ნებისმიერი | მხოლოდ შენიშვნის ტექსტი | ❌ არ იცვლება |
| 6 |      **კი**      | ნებისმიერი | ნებისმიერი | ❌ არ იცვლება (გაყინულია) |

## პირობა კოდში (ფაქტობრივი ლოგიკა)

```java
shouldUpdate =

    && ( ( isNewStatusInProgress && projectIdChanged )  // 1) ახალი სტატუსი „პროცესში" და პროექტის ნომერი დაიწერა/შეიცვალა
         || isMtbReturnTransition );                    // 2) MTB + ტიპი 6 + „პროცესში" → „დაბრუნებული"
```
